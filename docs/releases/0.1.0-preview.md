# LiveKit Console 0.1.0 preview

A self-hostable dashboard for LiveKit rooms, sessions, SIP, recordings and agent workers.

This is an early preview. Build and type checks run in CI; automated behavioral coverage is still limited.

## Install

Requirements: Node.js 22.13 or newer, npm, and a configured self-hosted LiveKit server. Docker is also supported.

```bash
git clone --branch v0.1.0-preview.1 https://github.com/unpod-ai/livekit-console.git
cd livekit-console
cp .env.example .env
# Fill in the LiveKit credentials, admin credentials and a random SESSION_SECRET.
npm ci
npm run build
npm start
```

See [getting started](https://github.com/unpod-ai/livekit-console/blob/main/docs/getting-started.md) for webhook
configuration and Docker instructions. Use HTTPS for production access.

## Included

Room and participant management, SIP trunks and dispatch rules, egress and ingress management, webhook history,
agent worker monitoring, role-based console accounts and optional repository traffic charts.

This preview includes the Vite/React Router security updates, a full-width responsive layout, repository traffic
loading/error states and saved range fixes. See the
[backup and restore guide](https://github.com/unpod-ai/livekit-console/blob/v0.1.0-preview.1/docs/deployment.md#back-up-the-database)
and [coverage and validation checklist](https://github.com/unpod-ai/livekit-console/blob/v0.1.0-preview.1/docs/parity-and-validation.md).

## Known limitations

- Historical data starts when collection is enabled; retained egress records only provide partial backfill.
- Some Cloud telemetry is unavailable, and SIP direction is inferred.
- Worker status requires configured worker endpoints.
- Private recording URLs require your own storage access.
- A real inbound provider call remains an acceptance check; recorded outbound call cross-links have been checked.
