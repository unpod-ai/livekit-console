# LiveKit Console v0.2.0

Agent and session timings are now visible where operators investigate calls, alongside a cleaner console UI,
restored near-black dark appearance and runtime branding support. This release builds on v0.1.0.

## Agent and session insights

- Show response latency, LLM time to first token (TTFT), TTS time to first audio (TTFB) and supported speech/turn
  delays directly beneath transcript messages. Select a timing to inspect the exact metric and seek its recording.
- Add compact session timing summaries and clearly scoped report-level model identities.
- Add an agent overview latency breakdown with p50, p95 and sample counts; open measured trends and contributors
  through the dedicated Latency tab.
- Include transcription, end-of-turn and callback timings reported on user messages. User messages cannot contribute
  LLM/TTS/response values. Preserve source agent names and independent measurement populations.
- Restore exact live telemetry selections outside the current page, retaining native record IDs separately from
  canonical message IDs. Keep transcript, trace, session-log and metric views separate and URL-backed.

## Console interface

- Simplify Agents and keep current/archived worker history behind each agent's Workers tab.
- Refine Overview, Usage, Performance, Sessions, Calls, Egress, telephony routing, diagnostics, Operations, Settings,
  agent testing and repository traffic with clearer hierarchy, compact forms and contextual details.
- Improve keyboard navigation, focus restoration, menu positioning, searchable long-list pickers and native selects
  with platform fallbacks. Refresh, automatic refresh and time-range controls remain independently usable.
- Add labelled mobile navigation, responsive primary record lists with sorting, readable investigation drawers,
  wrapped long session names and compact recording actions.
- Restore the deep neutral night canvas with softer semantic/chart colours; preserve Light/Dark/System appearance.

## Runtime branding

- Configure the name, footer domain, logo and favicon using `CONSOLE_NAME`, `CONSOLE_DOMAIN`, `CONSOLE_LOGO_URL`
  and `CONSOLE_FAVICON_URL`. Logos navigate home; production HTML receives the escaped runtime title/favicon.
- Expose only validated public display settings. Deployment-specific assets and credentials are not included.

## Upgrade and validation

Upgrade the console image/source and restart the console. No new database migration, credential change or agent
worker restart is required. Retained telemetry supplies the new views; collection remains opt-in and existing content
grants still apply. Back up the database and environment before upgrading.

Validation includes production web/server builds, 138 server tests, 72 Python tests and browser checks covering transcript/metric
selection, playback seek, source scoping, grants, controls, responsive layouts and both themes. Retained live-call
acceptance compared 20 displayed timing values to their stored report, verified private recording seek/reload and
confirmed uninterrupted agent worker uptime. Deployment/RTC browser checks also passed before publication.

Missing native timings remain unavailable. Transcription delay is distinct from STT processing duration. Model
identities are job/report-level; this release does not infer per-turn model attribution or managed Cloud services.
Progressively styled native selects fall back to the platform picker. Physical-device and full screen-reader
certification remain outside the automated validation.
