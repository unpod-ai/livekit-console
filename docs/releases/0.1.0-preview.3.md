# LiveKit Console v0.1.0-preview.3

This Phase 1 preview adds SDK-reported model usage to **Sessions → Agent Insights**. It does not complete the
Cloud parity roadmap.

## Included

- Version-2 report uploads with allowlisted per-provider/model LLM, STT, TTS, interruption and end-of-turn counters.
- Token/cache breakdowns, speech seconds, characters and request counts, with explicit missing/incomplete states.
- Strict numeric, size and duplicate-row validation. Usage shares report retention, export and admin-only access.
- Backward-compatible version-1 ingestion and retry digests.
- Updated Python helper, upgrade guidance and regression coverage.

## Upgrade

Back up the database and deploy the console first. Then replace the Python upload helper in your agent image;
it sends version 2. Existing version-1 workers continue to upload successfully. Existing finalized reports cannot
be overwritten or backfilled with new usage. No new configuration or database migration is needed beyond the
existing opt-in report integration.

See the [agent telemetry guide](https://github.com/unpod-ai/livekit-console/blob/v0.1.0-preview.3/docs/agent-telemetry.md).

## Limits and validation

Counts describe SDK-reported usage for the selected final report, not provider invoices. Cached and modality
tokens are subsets, not additional consumption. Project-wide aggregation, pricing, live traces/logs and automatic
PII redaction remain open. A real report requires a native instrumented AgentSession; room webhooks cannot
reconstruct it.

Validation covers legacy compatibility, usage normalization, malformed counters, retries/conflicts, admin access,
expiry, uploader behavior, browser rendering/export and production builds. Synthetic integration probes validate
transport without claiming real-call usage accuracy.
